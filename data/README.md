# Data

The raw fUSI recording is not included in this repository. Put one run's files here:

| File | Contents |
|---|---|
| `pwd.nii` or `pwd.nii.gz` | 4-D power Doppler volume (x, y, z, t); the example run is 117 × 56 × 50 voxels at 0.513 mm, 254 frames |
| `logs.parquet` | One row per volume; `time_ns` gives exact frame timestamps |
| `task_events.tsv` | BIDS-style events: `onset`, `duration`, `trial_type` (`Speech` / `Audio only`) |

Everything else (stimuli, TRIBE predictions, registered data) is generated by the pipeline.
